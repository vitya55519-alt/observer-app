# 🚀 Observer - Быстрый старт

## ⚡ За 5 минут до первого теста

### Требования
- ✅ Docker Desktop установлен и запущен
- ✅ Git установлен
- ✅ curl установлен (идет с Windows 10+)

### Шаг 1: Запустить сервер (2 минуты)

```bash
# Запустить меню
observer_menu.bat

# Выбрать опцию 2: Start Server
```

**Что произойдет:**
- Создается `.env` файл с случайными паролями
- Docker скачивает образы (~500 МБ при первом запуске)
- Запускаются 4 контейнера
- Сервер доступен по `http://localhost:8000`

**Проверить статус:**
```bash
# Опция 5: Check Server Status
```

Должны быть 4 контейнера со статусом `Up`:
```
NAME       STATUS
caddy      Up
api        Up
db         Up
cron       Up
```

---

### Шаг 2: Построить APK (3-5 минут)

```bash
# Запустить меню
observer_menu.bat

# Выбрать опцию 1: Build APK
```

**Что произойдет:**
- Docker скачивает Android SDK (~3 ГБ при первом запуске)
- Строит APK (~10-15 минут в зависимости от интернета)
- Сохраняет результат в `android/app-release.apk`

**При ошибках:**
```bash
# Проверить логи сборки
docker logs observer-temp 2>&1 | tail -100
```

---

### Шаг 3: Скопировать APK на сервер

```bash
# После успешной сборки
copy android\app-release.apk server\dist\app.apk
```

Теперь APK доступен по адресу:
```
http://localhost/app/app.apk
```

---

### Шаг 4: Создать код привязки

## 📱 Установка на устройство

### Вариант A: Физическое устройство через ADB

```bash
# 1. Включить Developer Mode на устройстве
# Settings > About > Build Number (нажать 7 раз)

# 2. Включить USB Debug
# Settings > Developer Options > USB Debugging

# 3. Подключить через USB

# 4. Установить APK
adb install android\app-release.apk
```

### Вариант B: Эмулятор Android

```bash
# 1. Открыть Android Studio
# 2. Tools > Device Manager > Create Device
# 3. После загрузки эмулятора:

adb install android\app-release.apk
```

### Вариант C: Установить вручную

1. Перекинуть `android/app-release.apk` на телефон
2. Открыть файловый менеджер
3. Нажать на APK → Установить

## ⚙️ Первый запуск приложения

После установки:

1. **Открыть приложение**
   - Выбрать "Наблюдатель" в меню приложений

2. **Ввести адрес сервера**
   - На локальной машине: `http://192.168.1.XXX:8000`
   - (узнать IP: `ipconfig` в PowerShell, найти IPv4)
   - Или через ngrok (см. ниже)

3. **Ввести код привязки**
   - Код, полученный через `Create Device Code`

4. **Ввести имя устройства**
   - Например: `MyPhone` или `TestDevice`

5. **Нажать "Привязать"**

## 🌐 Доступ через интернет (ngrok)

Если нужен доступ с другого компьютера/сети:

```bash
# 1. Установить ngrok
choco install ngrok

# 2. Запустить туннель
ngrok http 443 --domain yourdomain.ngrok.io

# 3. В приложении использовать выданный URL
# Например: https://yourdomain.ngrok.io
```

## 🆘 Типичные ошибки

### "Docker is not running"
```
Решение: Запустить Docker Desktop
```

### "curl: command not found"
```
Решение: Установить через Chocolatey
choco install curl
```

### "APK build failed"
```
Решение: 
1. Увеличить диск (SDK ~3ГБ)
2. Проверить интернет
3. Перезагрузить Docker
docker system prune
```

### "Cannot connect to localhost:8000"
```
Решение:
1. Проверить статус: observer_menu.bat → 5
2. Проверить логи: observer_menu.bat → 6
3. Перезагрузить: docker compose restart
```

### "Code rejected" при привязке
```
Решение:
1. Код одноразовый
2. Создать новый: observer_menu.bat → 3
3. Проверить правильность ввода
```
