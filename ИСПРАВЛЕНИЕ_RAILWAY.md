# 🔧 Исправление ошибки Railway

## ❌ Проблема: "Railpack не удалось подготовить сборку"

Railway пытается собрать проект из корня, но нужно из `server/app/`

---

## ✅ Решение (2 минуты)

### Способ 1: Через настройки (рекомендуется)

1. В Railway → откройте ваш сервис
2. Перейдите в **Settings**
3. Найдите **Root Directory**
4. Введите: `server/app`
5. **Deploy** → Railway перезапустится

### Способ 2: Через railway.toml

Я создам правильный конфигурационный файл в корне проекта.

---

## 🔍 Дополнительная диагностика

Если после установки Root Directory всё равно ошибка:

1. **View Logs** → смотрите что конкретно не так
2. Обычные проблемы:
   - `requirements.txt not found` → Root Directory неправильный
   - `Python not found` → Railway не понял что это Python проект
   - `DATABASE_URL not found` → PostgreSQL не добавлена

---

## 🚀 Правильная структура для Railway

Railway должен видеть в `server/app/`:
```
server/app/
  ├── main.py          ← FastAPI приложение
  ├── req.txt          ← зависимости Python
  ├── Procfile         ← команда запуска
  ├── railway.toml     ← конфигурация (опционально)
  ├── panel/           ← веб-панель
  └── dist/            ← APK файлы
```

---

## 📋 Пошаговая инструкция

1. Railway → ваш проект → сервис `observer-app`
2. **Settings** (иконка шестеренки)
3. Прокрутите вниз до **Root Directory**
4. Введите: `server/app`
5. Нажмите где-то вне поля (чтобы сохранилось)
6. **Deployments** → нажмите **Deploy**
7. Подождите 1-2 минуты

Должно появиться: ✅ **Deployed**

---

## 🎯 Если всё равно не работает

Попробуйте пересоздать проект:

1. Railway → удалите текущий проект
2. **+ New Project** → **Deploy from GitHub repo**
3. Выберите `vitya55519-alt/observer-app`
4. **СРАЗУ** после создания:
   - Settings → Root Directory → `server/app`
5. Добавьте PostgreSQL
6. Добавьте переменные окружения
