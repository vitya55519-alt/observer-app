# 🚀 Полное руководство по сборке и развертыванию Observer

## 📱 Часть 1: Сборка APK

### Шаг 1: Подготовка в Android Studio

1. Откройте Android Studio
2. **File** → **Open** → выберите папку `android/`
3. Дождитесь синхронизации Gradle (может занять 5-10 минут при первом запуске)
4. Если есть ошибки SDK, следуйте подсказкам Android Studio для установки недостающих компонентов

### Шаг 2: Сборка APK

**Вариант A: Через Android Studio (рекомендуется)**
```
Build → Build Bundle(s) / APK(s) → Build APK(s)
```

**Вариант B: Через командную строку**
```
cd android
./gradlew.bat assembleRelease
```

**Результат:**
```
android/app/build/outputs/apk/release/app-release.apk
```

### Шаг 3: Подпись APK (опционально)

Если нужна production подпись:
```
cd android
./gradlew.bat assembleRelease -Pandroid.injected.signing.store.file=path/to/keystore.jks \
  -Pandroid.injected.signing.store.password=password \
  -Pandroid.injected.signing.key.alias=alias \
  -Pandroid.injected.signing.key.password=keypassword
```

## 🖥️ Часть 2: Развертывание сервера локально

### Требования
- Docker Desktop установлен
- PostgreSQL (если не использовать Docker)
- Python 3.12+ (если не использовать Docker)

### Шаг 1: Инициализация .env файла

```bash
cd server
cp .env.example .env
bash scripts/init.sh
```

Это создаст случайные пароли и токены:
```
ADMIN_PASSWORD=a1b2c3d4e5f6
SECRET=7f8e9d0c1b2a3f4e5d6c7b8a9f0e1d2c
DB_PASS=a1b2c3d4e5f6
DATABASE_URL=postgresql://obs:a1b2c3d4e5f6@db:5432/obs
```

### Шаг 2: Редактирование .env

```bash
nano .env
```

Измените:
```
DOMAIN=localhost
```

(Для продакшена используйте реальный домен или IP)

### Шаг 3: Создание необходимых директорий

```bash
mkdir -p dist
mkdir -p server/panel
```

### Шаг 4: Запуск Docker Compose

```bash
docker compose up -d --build
```

**Проверка статуса:**
```bash
docker compose ps
```

Должно быть 4 контейнера:
- `caddy` (веб-сервер с HTTPS)
- `api` (FastAPI приложение)
- `db` (PostgreSQL)
- `cron` (резервные копии и очистка)

## 🌐 Часть 3: Настройка для localhost

Так как используется localhost, нужны небольшие изменения:

### Вариант A: Использовать http://localhost

1. **Отредактировать `server/Caddyfile`:**
```
# Закомментировать SSL требования
http://localhost {
    encode gzip
    reverse_proxy api:8000
}
```

2. **Перезапустить сервер:**
```bash
docker compose restart caddy
```

3. **В Android приложении использовать:**
```
http://localhost:8000
```

### Вариант B: Использовать ngrok для тестирования (рекомендуется)

```bash
# Установка ngrok
choco install ngrok

# Запуск туннеля
ngrok http 443 --domain=yourdomain.ngrok.io

# В Android приложении используйте выданный URL
```

## 🔐 Часть 4: Веб-панель администратора

### Доступ к панели

**Локально:**
```
http://localhost/panel/
```

**Через ngrok:**
```
https://yourdomain.ngrok.io/panel/
```

### Логин

- **Пароль:** значение `ADMIN_PASSWORD` из `.env`

### Создание кода привязки

```bash
# Получить пароль из .env
ADMIN_PASS=$(grep ADMIN_PASSWORD server/.env | cut -d= -f2)

# Создать новый код
curl -X POST \
  -H "X-Admin-Token: $ADMIN_PASS" \
  http://localhost:8000/api/codes
```

**Ответ:**
```json
{"code": "A1B2C3"}
```

Этот код вводится в Android приложение при привязке.

```bash

# Теперь доступно по ссылке
# http://localhost/app/app.apk
```

## 🧪 Тестирование локально

### 1. Убедитесь, что все работает

```bash
# Проверить API
curl http://localhost:8000/api/devices \
  -H "X-Admin-Token: YOUR_ADMIN_PASSWORD"

# Должен вернуть пустой массив []
```

### 2. Запустить Android приложение на эмуляторе

```bash
# Открыть эмулятор Android в Android Studio
# Или подключить физическое устройство через ADB

# В приложении ввести:
# - Адрес сервера: http://YOUR_PC_IP:8000
#   (узнать: ipconfig в PowerShell)
# - Код привязки: A1B2C3 (из curl команды выше)
# - Имя устройства: TestDevice
```

### 3. Проверить панель

После привязки устройство должно появиться в панели:
```
http://localhost/panel/
```

## 🚨 Частые проблемы

### APK не собирается

**Проблема:** `ANDROID_HOME не установлен`
```bash
# Решение: установить переменную окружения
setx ANDROID_HOME "C:\Users\YourUser\AppData\Local\Android\Sdk"
setx JAVA_HOME "C:\Program Files\Android\Android Studio\jbr"
# Перезагрузиться
```

### Docker не запускается

```bash
# Проверить статус
docker compose logs

# Перезагрузить
docker compose down
docker compose up -d --build
```

### Приложение не подключается к серверу

1. Убедитесь, что сервер запущен:
```bash
docker compose ps
```

2. Проверьте IP адрес ПК:
```powershell
ipconfig
```
Используйте IPv4 адрес, например `192.168.1.100`

3. В приложении используйте:
```
http://192.168.1.100:8000
```

### "Код отклонён" при привязке

- Проверьте, что код правильно введен
- Коды одноразовые - создайте новый через curl
