## 🚀 Сценарий 1: Полная автоматизация (РЕКОМЕНДУЕТСЯ)

### Установить Docker Desktop
1. Скачать: https://www.docker.com/products/docker-desktop
2. Установить (перезагрузка потребуется)
3. Запустить Docker Desktop
4. Запустить: `observer_menu.bat`

**Плюсы:**
- ✅ Одна кнопка - всё работает
- ✅ Не нужно настраивать PostgreSQL
- ✅ Изолированная среда
- ✅ Автоматическая сборка APK

**Минусы:**
- ⏱️ Первая загрузка ~4 ГБ
- 💾 Занимает ~10 ГБ на диске

## 🛠️ Сценарий 2: Ручная настройка (БЕЗ Docker)

### A. Для сборки APK

**Установить Android Studio:**
1. Скачать: https://developer.android.com/studio
2. Установить с SDK
3. Открыть проект `android/`
4. `Build → Build APK(s)`

**Готовый APK будет:**
```
android\app\build\outputs\apk\release\app-release.apk
```

### B. Для сервера

**Установить PostgreSQL:**
```powershell
# Вариант 1: Через Chocolatey (если установлен)
choco install postgresql

# Вариант 2: Скачать установщик
# https://www.postgresql.org/download/windows/
# Запомните пароль, который зададите при установке!
```

**Настроить базу данных:**
```sql
-- Открыть SQL Shell (psql) из меню Пуск
-- Логин: postgres, пароль: тот что задали при установке

CREATE DATABASE obs;
CREATE USER obs WITH PASSWORD 'yourpassword';
GRANT ALL PRIVILEGES ON DATABASE obs TO obs;
\c obs
\i 'C:/путь/к/проекту/server/app/schema.sql'
```

**Запустить сервер:**
```powershell
# 1. Настроить .env
cd server
copy .env.example .env
notepad .env
# Изменить DATABASE_URL, пароли

# 2. Запустить
start_server_local.bat
```

## ⚡ Самый быстрый способ ПРЯМО СЕЙЧАС

Если хотите увидеть результат за 5 минут:

### 1. Установить только Android Studio
```
https://developer.android.com/studio
```

### 2. Открыть проект
```
File → Open → выбрать папку "android"
Ждать Gradle Sync
```

### 3. Собрать APK
```
Build → Build Bundle(s) / APK(s) → Build APK(s)
Ждать 5-10 минут
```

### 4. Найти APK
```
android\app\build\outputs\apk\release\app-release.apk
```

Этот APK можно установить на телефон уже сейчас!

Для сервера - потом установите Docker или PostgreSQL.
