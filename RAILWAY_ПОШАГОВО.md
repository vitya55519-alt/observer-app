## 🚀 RAILWAY DEPLOY В 7 ШАГОВ

### ШАГ 1: Откройте Railway Dashboard

```
https://railway.app/dashboard
```

Если не залогинены - нажмите **Sign up with GitHub**

---

### ШАГ 2: Создайте новый проект

1. Нажмите **+ New Project**
2. Выберите **Deploy from GitHub repo**
3. Найдите `vitya55519-alt/observer-app`
4. Нажмите на неё → **Deploy**

⏳ **Подождите 1-2 минуты...**

Railway автоматически начнёт деплой!

---

### ШАГ 3: Установите Root Directory

**Важно!** Railway должен запускать приложение из `server/app`:

1. В проекте нажмите на сервис `observer-app` (должен быть ❌ если ещё не настроен)
2. Нажмите **Settings**
3. Найдите **Root Directory**
4. Введите: `server/app`
5. Нажмите **Deploy**

⏳ **Подождите перезагрузки (~1 минута)**

---

### ШАГ 4: Добавьте PostgreSQL базу данных

1. В проекте Railway нажмите **+ New Service**
2. Нажмите **Add Database**
3. Выберите **PostgreSQL**
4. Подождите создания (~30 секунд)

✅ Railway **автоматически** создаст переменную `DATABASE_URL`!

---

### ШАГ 5: Установите переменные окружения

1. Нажмите на сервис `observer-app` (не на БД!)
2. Откройте вкладку **Variables**
3. Нажмите **+ New Variable** и добавьте по одной:

**Переменные:**

| Переменная | Значение | Пример |
|-----------|---------|--------|
| ADMIN_PASSWORD | Придумайте пароль | `SuperSecret123!@#` |
| SECRET | Минимум 32 символа | `YourSecretKeyMin32CharsLength1234567890AB` |
| DOMAIN | Оставьте пустым | (обновим позже) |
| TG_TOKEN | Пусто | (опционально) |
| TG_CHAT | Пусто | (опционально) |

✅ **DATABASE_URL** уже существует (создана PostgreSQL)!

---

### ШАГ 6: Получите публичный домен

1. На сервисе `observer-app` нажмите **Settings**
2. Найдите **Networking**
3. Нажмите **Generate Domain**
4. Скопируйте полученный URL (например: `observer-app-production-a1b2c3.up.railway.app`)

---

### ШАГ 7: Обновите DOMAIN переменную

1. Вернитесь в **Variables**
2. Найдите `DOMAIN`
3. Установите значение: `observer-app-production-a1b2c3.up.railway.app`
   *(БЕЗ https://, только домен!)*
4. Нажмите **Deploy**

⏳ **Подождите перезагрузки (~1 минута)**

---

## 🔐 СОЗДАЙТЕ КОД ПРИВЯЗКИ

Откройте веб-панель и нажмите кнопку создания кода, или используйте curl:

```bash
curl -X POST \
  https://observer-app-production-a1b2c3.up.railway.app/api/codes \
  -H "X-Admin-Token: SuperSecret123!@#"
```

**Ответ:**
```json
{"code": "ABC123"}
```

**Скопируйте этот код!** Он нужен для привязки устройства в приложении.

## 📱 УСТАНОВИТЕ APK

### Скачайте APK из GitHub Actions

1. Откройте: https://github.com/vitya55519-alt/observer-app/actions
2. Найдите последний успешный workflow "Build APK"
3. Нажмите на него
4. Скачайте **Artifacts** → `app-release.apk`

### Установите на телефон

**Способ 1: Через ADB (USB)**
```bash
adb install app-release.apk
```

**Способ 2: Вручную**
1. Скопируйте APK на телефон
2. Откройте файловый менеджер
3. Нажмите на APK → Установить

## 🔍 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Проверьте логи Railway

1. Railway Dashboard → проект → сервис `observer-app`
2. **Deployments** → последний деплой
3. **View Logs** → смотрите ошибки

### Частые ошибки

| Ошибка | Решение |
|--------|---------|
| `DATABASE_URL not found` | Добавьте PostgreSQL |
| `Port already in use` | Очистите переменные и перезагрузитесь |
| `Timeout connection` | Подождите - Railway может быть на холодном старте |
| `Panel not found` | Проверьте Root Directory = `server/app` |
| `401 Unauthorized` | Проверьте ADMIN_PASSWORD в Variables |

### Если сервис не запускается

1. Railway → **Deployments** → посмотрите логи
2. Скопируйте текст ошибки
3. Попробуйте нажать **Deploy** снова
