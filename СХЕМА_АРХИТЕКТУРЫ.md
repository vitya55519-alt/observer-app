## 🔐 БЕЗОПАСНОСТЬ

```
┌──────────────────────────────────────────┐
│            Уровни защиты                 │
└──────────────────────────────────────────┘

1. Транспорт:
   ✅ HTTPS (Railway auto)
   ✅ WSS для WebSocket

2. Аутентификация:
   ✅ X-Admin-Token для панели
   ✅ X-Device-Token для устройств
   ✅ Одноразовые коды привязки

3. База данных:
   ✅ Пароли в переменных окружения
   ✅ PostgreSQL внутри Railway сети

4. Медиа файлы:
   ✅ HMAC подпись URL
   ✅ Временные ссылки (1 час)

⚠️ Рекомендации для продакшена:
   - Шифрование токенов на устройстве
   - Rate limiting на API
   - Логирование доступа
   - Backup БД
```
